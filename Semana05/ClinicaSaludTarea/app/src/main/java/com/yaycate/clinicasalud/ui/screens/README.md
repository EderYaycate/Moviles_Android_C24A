## Requerimientos funcionales

**1. Inicio**
Lista de médicos con ícono, especialidad y calificación. Arriba hay chips para filtrar por especialidad (Cardiología, Pediatría, etc).

**2. Perfil del médico**
Al tocar un doctor te lleva a su perfil, ahí escoges una fecha y una hora (chips seleccionables, solo una de cada). El botón "Agendar cita" no se habilita hasta elegir ambas.

**3. Confirmación + Mis citas**
Después de agendar se muestra un resumen de la cita. Esa cita se guarda y se puede ver en "Mis citas", diferenciando si está Confirmada o Completada.

**4. Menú lateral (Drawer)**
Con el ícono de las 3 rayitas se abre un menú con 3 opciones: Inicio, Mis citas e Historial médico.
